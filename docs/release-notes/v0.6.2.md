Lyrion Anywhere **0.6.2** adds diagnostics to the web player so that the scrubbing problem some iPhone and iPad users see (issue #12) can be pinned down from the app's own Connection log. Playback behaviour is unchanged. Everything else is as in [0.6.1](https://github.com/JameZUK/lyrion-anywhere/releases/tag/v0.6.1) and [0.6.0](https://github.com/JameZUK/lyrion-anywhere/releases/tag/v0.6.0), which added the built-in Cloudflare Tunnel. Android [1.15.5](https://github.com/JameZUK/lyrion-anywhere/releases/tag/android-v1.15.5) remains current. Update from *Settings › Plugins* in LMS; LMS restarts to load it. The web app updates itself in the background and offers a reload when it is ready.

**Install or update:** add this repository in *Settings › Plugins › Additional repositories* (if you haven't already), then install or update **Lyrion Anywhere**:

```
https://github.com/JameZUK/lyrion-anywhere/releases/latest/download/repo.xml
```

## Web app

- **The Connection log now shows the conversation with LMS (#12).** *Settings › About › Advanced › Diagnostics* lists each stream command LMS sends and its flags (`lms: strm s autostart=1 format=f threshold=255`, `lms: strm p`, …), each status the player sends back with a short gloss (`player: STMl (loaded, waiting for LMS to start it)`), the player's state changes and their cause (`player: Playing → Paused (after strm p)`), the commands the page sends to LMS on its own, the media element's events with the play head and what is buffered (`media: waiting at 61.2 s, buffered 60.9–75.4 s`), when the element stops consuming audio or the download is parked because the player's buffer is full, and the outcome of the clean-end check added in 0.6.1. Lines of one kind are limited to one per five seconds; the report a device sends to the server carries up to 120 lines. Nothing personal is logged.

If a scrub still misbehaves for you, please post the Connection log for that minute on issue #12.

The full list is in the [changelog](https://github.com/JameZUK/lyrion-anywhere/blob/main/CHANGELOG.md).
