Lyrion Anywhere **0.4.0** brings the server side up to date with Android [1.14.0](https://github.com/JameZUK/lyrion-anywhere/releases/tag/android-v1.14.0), and gives the web app a thorough tidy-up. Update from *Settings › Plugins* in LMS; LMS restarts to load it.

**Install or update:** add this repository in *Settings › Plugins › Additional repositories* (if you haven't already), then install or update **Lyrion Anywhere**:

```
https://github.com/JameZUK/lyrion-anywhere/releases/latest/download/repo.xml
```

**Android app:** this release also carries the Android app [1.14.0](https://github.com/JameZUK/lyrion-anywhere/releases/tag/android-v1.14.0), the version that goes with it. `LyrionAnywhere-android-1.14.0.apk` installs on any phone; the per-ABI APKs are smaller. Check them against `SHA256SUMS-android.txt`.

## Highlights

**Gateway**
- **Riding out a busy music server:** when LMS stops answering for a while (for example while its music drive spins up), the gateway tells the apps it is busy and refuses new requests at once instead of letting them pile up, notices when LMS answers again, and keeps players' connections alive meanwhile.
- **Change your own password:** a signed-in user can change their password from the apps (the current password, and the authenticator code if two-step is on, are checked first, and other devices can be signed out at the same time).
- **Save the queue as a playlist** from any player you may control.
- **Slow LMS requests are logged** with the command and how long it took, to help find what holds LMS up.
- **Opus decodes about 80 times faster,** in the gateway and in the web player.

**Web app**
- **A calmer, tidier app.** Every screen was reviewed for clutter:
  - No "Playing on" strip: the mini player names the player in use, and moving playback is in *Play on…*.
  - Play · Shuffle · Download · ⋯ on album, artist and playlist pages, and one ⋯ per row elsewhere.
  - Settings is seven sections, each with its own page and a one-line summary.
  - One status line at the top, and one message at a time.
  - Library is one row of sections, and the desktop sidebar has seven entries instead of fourteen.
  - Rooms and *Play on…* share one player list.
  - Downloads play through the normal player screens.
- **Controls that work when your server is out of reach:** controls that can't work are greyed out; when the browser is the player, play/pause and skipping between tracks it holds keep working, and the queue marks downloaded tracks.
- **A busy server is shown calmly** as busy, not as an error or offline.
- **Downloads:** tracks, playlists and artists as well as albums, a storage limit and a Wi-Fi only setting.
- **Continue on a player** when you are back online, **change your password**, and **save the queue as a playlist**.
- **Fixed:** going offline could reload the page and leave it on the start-up screen; the app now keeps your place and signs you back in when the server returns.
