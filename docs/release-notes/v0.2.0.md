Lyrion Anywhere **0.2.0** brings the server side up to date with the native Android app ([1.1.0](https://github.com/JameZUK/lyrion-anywhere/releases/tag/android-v1.1.0)) and adds many improvements for the web app. Update from *Settings › Plugins* in LMS; LMS restarts to load it.

**Install or update:** add this repository in *Settings › Plugins › Additional repositories* (if you haven't already), then install or update **Lyrion Anywhere**:

```
https://github.com/JameZUK/lyrion-anywhere/releases/latest/download/repo.xml
```

## Highlights

**Adding devices**
- **QR codes:**
  - *Add a device* on the plugin's settings page shows a one-time code and a QR code for a user;
  - users can add their own devices from the web app (*Settings › Account › Add another device*);
  - the Android app scans the QR code, and `lyrion-anywhere://pair` links open it.
- **Device details:**
  - each device shows its type (installed web app, browser or Android app), platform and last address, as passed through your reverse proxy;
  - devices can be renamed by an admin or by their user, and the name is also the player's name in LMS.

**Playing**
- **Player-first:** each device plays by default. Other players are a tap away (*Play on…*), and **Transfer** moves the queue and position between players.
- **Better sync with your Squeezeboxes:**
  - phones and browsers report the audio you actually hear;
  - synced groups start together;
  - LMS's corrections apply at once.
- **Waveform seek bar:**
  - tracks are analysed on the server (loudness, waveform);
  - tapping the waveform jumps there, and starts playback if it was paused or stopped.
- **Faster FLAC starts:** large embedded artwork is no longer sent with FLAC streams (about 2.6× faster to first audio on slow links).
- **Fixes:**
  - seeks and volume take effect at once;
  - tracks no longer stop part-way when a player paused or buffered for a minute;
  - many reconnect and resume improvements;
  - "now playing" stays right when LMS's queue holds a track it can't resolve.

**Your library**
- **New browsing:** New Music, Genres, Years, Compilations, Random Albums, the Music Folder, artists by role and LMS virtual libraries, plus album sorting.

**Offline**
- **Play counts:** plays made offline in the web and Android apps are now counted in LMS (play count and last played) when the device is back online.

**Settings page**
- **New:** a logo; a 90-day "stay signed in" default; the plugin list shows loading and errors; page updates are never hidden by the browser cache.
- **Fixed:** special characters now display correctly.

**Security**
- **Review fixes:** a security review of everything added since 0.1.0. Its fixes include rate limits on renaming and pairing, play-count de-duplication, the settings page's admin commands needing the page's own token, and crash-report redaction. See `docs/security/` in the repository.
- **Upgrade note:** the database is migrated automatically on first start (migrations 7–9).

The full list is in [CHANGELOG.md](https://github.com/JameZUK/lyrion-anywhere/blob/main/CHANGELOG.md).
