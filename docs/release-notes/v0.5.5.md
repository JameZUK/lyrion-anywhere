Lyrion Anywhere **0.5.5** makes internet radio play. Everything else is as in [0.5.4](https://github.com/JameZUK/lyrion-anywhere/releases/tag/v0.5.4). Android [1.15.4](https://github.com/JameZUK/lyrion-anywhere/releases/tag/android-v1.15.4) remains current. Update from *Settings › Plugins* in LMS; LMS restarts to load it.

**Install or update:** add this repository in *Settings › Plugins › Additional repositories* (if you haven't already), then install or update **Lyrion Anywhere**:

```
https://github.com/JameZUK/lyrion-anywhere/releases/latest/download/repo.xml
```

## What changed

- **Internet radio (Shoutcast and other stations) plays.** LMS tells a capable player to fetch a station straight from the broadcaster (*direct streaming*), which these players never do: they only ever talk to the gateway, so the gateway refused that instruction, as it must, and the station stayed silent with "Decoder does not support file format" in `server.log`. The gateway now sets LMS's *MP3 streaming method* to *proxied* for each Lyrion Anywhere player the first time LMS talks to it (the setting covers every internet stream, not only MP3, and LMS keeps it). If a direct stream still arrives, the gateway sets it and has LMS replay the station through itself, at most three times in a row. Nothing to configure; on an older plugin, set *Settings › Player › Audio › MP3 streaming method* to *Proxied* by hand.
- Tests: `lms_is_told_to_proxy_once_the_player_is_known` and `a_refused_direct_stream_is_replayed_through_lms_up_to_three_times`; the stream lock-down tests ignore the gateway's own commands to LMS.

The full list is in the [changelog](https://github.com/JameZUK/lyrion-anywhere/blob/main/CHANGELOG.md).
