Lyrion Anywhere **0.7.4** is a small release: the web app's mini player and its signal path on a desktop, and the project's documentation rewritten. The player protocol stays at 2, so **Lyrion Anywhere for Android 1.17.0** or later keeps working; 1.17.1, released alongside, makes the same mini-player change on the phone. Nothing has to be updated together this time.

**Install or update:** add this repository in *Settings › Plugins › Additional repositories* (if you haven't already), then install or update **Lyrion Anywhere**:

```
https://github.com/JameZUK/lyrion-anywhere/releases/latest/download/repo.xml
```

## The web app

- **The mini player shows the badge's verdict word alone**: *Hi-Res*, *Lossless*, *Transcoded* or *Lossy*, amber when the badge is, after the artist, which keeps its room. In 0.7.3 the full badge could cut the artist's name short on a phone. The full badge stays on Now playing.
- **The signal path is a row on a desktop.** The sheet is wider on a wide screen, the three blocks sit in one row with arrows between them, and the quality switch with its caption sits on its own line beneath, so *Data saver* no longer wraps. Phones keep the stacked layout.

## Documentation

- The README is now a landing page an ordinary person can read, with two walkthroughs ([Set up with a domain](https://github.com/JameZUK/lyrion-anywhere/blob/main/docs/SETUP-DOMAIN.md), with the built-in Cloudflare Tunnel, and [Set up over a VPN](https://github.com/JameZUK/lyrion-anywhere/blob/main/docs/SETUP-VPN.md)) that photograph the settings page at each step, [Under the bonnet](https://github.com/JameZUK/lyrion-anywhere/blob/main/docs/TECHNICAL.md) for the engineering, and a [screenshot gallery](https://github.com/JameZUK/lyrion-anywhere/blob/main/docs/SCREENSHOTS.md). Every screenshot was retaken with the new badge and signal path. The library, players, people and artwork in them are invented.

## Also in this release

- The gateway and the plugin's own code are unchanged since 0.7.3; this release carries the web app and the documentation.
- The built-in demo's fake Lyrion server now plays for real, which the screenshots needed, and has tests of its own.

The full list is in the [changelog](https://github.com/JameZUK/lyrion-anywhere/blob/main/CHANGELOG.md).
