Lyrion Anywhere **0.7.7** fixes artwork for streams. The player protocol stays at 2, so **Lyrion Anywhere for Android 1.17.0** or later keeps working. **Android 1.17.3** goes out alongside with the same fix on its side; either is enough on its own.

**Install or update:** add this repository in *Settings › Plugins › Additional repositories* (if you haven't already), then install or update **Lyrion Anywhere**:

```
https://github.com/JameZUK/lyrion-anywhere/releases/latest/download/repo.xml
```

## Artwork for streams

- **Streams showed no artwork** ([#37](https://github.com/JameZUK/lyrion-anywhere/issues/37)). The station or programme image LMS hands out for a stream (BBC Sounds, radio directories, most plugins) comes through LMS's own image proxy with no size, and asked for exactly that LMS answers with a redirect to the external image rather than the image itself. The gateway follows no redirects, on purpose, so the apps showed a placeholder. The gateway now asks LMS for the image itself when no size is given. The web app asks for a size, and shows a stream's artwork in now playing, the mini player, the queue, the car view and the room cards, which it did not before. Plugin menu icons at external URLs are fixed by the same change.
- **Nothing to do after updating.** An Android app older than 1.17.3 is fixed by this release alone; 1.17.3 is fixed on any plugin from 0.7.3.

The full list is in the [changelog](https://github.com/JameZUK/lyrion-anywhere/blob/main/CHANGELOG.md).
