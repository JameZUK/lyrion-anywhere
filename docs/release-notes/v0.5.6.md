Lyrion Anywhere **0.5.6** closes the remaining low findings of the October code review across the gateway, the web app, the plugin and the release process. It goes with Android [1.15.5](https://github.com/JameZUK/lyrion-anywhere/releases/tag/android-v1.15.5). Update from *Settings › Plugins* in LMS; LMS restarts to load it.

**Install or update:** add this repository in *Settings › Plugins › Additional repositories* (if you haven't already), then install or update **Lyrion Anywhere**:

```
https://github.com/JameZUK/lyrion-anywhere/releases/latest/download/repo.xml
```

## Gateway

- Admin-only plugins are hidden from listeners in artist info and lyrics as they are in RPC; invalid ids answer 404 like any unknown resource; oversize request bodies are refused before they are read; artwork honours LMS's busy state; the seek merge no longer loses a listening-history row; the transcode permit is held only for the encode; stricter playlist names; `Clear-Site-Data` on every rejected refresh.
- **Two visible changes:** the *Recently played* and *Most played* shelves on Home now come from your own listening only (they used to blend in the whole server's lists, which revealed other users' recent albums), so a new user's shelves start empty; and a track larger than the whole transcode cache (2 GB by default) is no longer offered as MP3 or Opus, only as the original.
- The player core bounds a server-sent rename and the developer CLI's direct mode refuses stream targets other than LMS. Five parsers gained random-input tests.

## Web app

- **Updates wait for you.** A new version no longer takes over open tabs: it installs in the background, keeps the previous version's files while any tab still uses them, and shows "A new version is ready. Reload when convenient." Until now an upgrade could leave an open tab without its pieces, and a reload stopped playback.
- A download that turns out not to be audio (a proxy's HTML page, say) fails cleanly instead of being stored as a track.
- A hung token refresh can no longer stall every tab and the player; sign-out clears the remembered players; busy guards on *Create playlist* and the two-step forms; a failed sign-out is reported; larger touch targets on the Home shelf, menu rows and library notes; the settings pickers work with the arrow keys.

## Plugin, CI and releases

- `anywhere status` without the plugin's token now tells a LAN caller only whether the gateway is running, not its paths, pid or recent errors.
- Releases carry build provenance attestations (`gh attestation verify`, see RELEASING.md). The CI audits npm packages, Dependabot now covers npm, Cargo and Gradle, and the licence policy allows GPL only for this project's own crates.
- The plugin only ever sends the admin secret to `127.0.0.1`, never through LMS's web proxy.

The full list is in the [changelog](https://github.com/JameZUK/lyrion-anywhere/blob/main/CHANGELOG.md).
