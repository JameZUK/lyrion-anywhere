Lyrion Anywhere **0.5.4** is a small follow-up to [0.5.3](https://github.com/JameZUK/lyrion-anywhere/releases/tag/v0.5.3): the web app's Settings › About now really shows the plugin's version. Everything else is as in 0.5.3 (the gateway's reads no longer wait for writes; the first GitHub issue fixes and the authentication hardening from 0.5.2). Android [1.15.4](https://github.com/JameZUK/lyrion-anywhere/releases/tag/android-v1.15.4) remains current. Update from *Settings › Plugins* in LMS; LMS restarts to load it.

**Install or update:** add this repository in *Settings › Plugins › Additional repositories* (if you haven't already), then install or update **Lyrion Anywhere**:

```
https://github.com/JameZUK/lyrion-anywhere/releases/latest/download/repo.xml
```

## What changed

- **Settings › About shows the plugin's version.** 0.5.3 took the version from the plugin's `install.xml` at build time, but the release build ran in a container that had only the web app's folder, so it quietly fell back to the package version and the zip still read "0.1.0". The container builds now carry `install.xml`, a build that cannot find it fails instead of guessing, and the release check refuses a zip whose web app does not show the plugin's version.

The full list is in the [changelog](https://github.com/JameZUK/lyrion-anywhere/blob/main/CHANGELOG.md).
