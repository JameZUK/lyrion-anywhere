The first release of **Lyrion Anywhere**: secure access to your Lyrion Music Server from anywhere, through one hardened gateway behind your HTTPS reverse proxy. LMS itself is never exposed.

**Install:** in LMS, open *Settings › Plugins*, add this repository under *Additional repositories*, then install **Lyrion Anywhere**:

```
https://github.com/JameZUK/lyrion-anywhere/releases/latest/download/repo.xml
```

The full walkthrough (HTTPS reverse proxy, users, first sign-in) is in [docs/INSTALL.md](https://github.com/JameZUK/lyrion-anywhere/blob/main/docs/INSTALL.md).

## Highlights

**Playing**
- Remote control for your LMS players. A browser can also be a player itself: lossless, decoded on the device, with background playback on phones and tablets (iPhone and iPad included).
- Picks up where you left off after a reload.

**Browsing**
- Albums, artists, playlists, favourites, search, and the queue (drag to reorder, swipe to remove).
- Sync groups.
- Apps, radio and plugins found automatically (for example AudioMuse-AI, Custom Browse and Random Mix), with an "Admins only" option per plugin.

**Offline**
- Download albums as original files, MP3 or Opus (the last two need `ffmpeg` on the server), and play them with no connection.

**The app**
- Installable on iPhone, iPad, Android and desktop.
- Themes: Material (with your accent colour), Classic and High contrast; light, dark or automatic.

**Security**
- **Accounts:** admin and listener roles, optional two-step verification, sign-in lockouts, and a configurable sign-in lifetime.
- **Commands:** a default-deny command allow-list. Plugin actions run only if LMS offered them to that device.
- **Responses:** filtered so file paths and LAN addresses never leave the gateway.
- **The page itself:** a strict Content Security Policy.
- **Testing:** every change is tested, including fuzz and negative tests, and a full security review was carried out before release.

## What's in the release

| File | What |
|---|---|
| `LyrionAnywhere-0.1.0.zip` | The LMS plugin. It includes gateways for Linux x86_64, aarch64 and armhf, and the web app. |
| `repo.xml` | The LMS plugin repository description, for *Additional repositories*. |
| `SHA256SUMS` | Checksums of the files above. |

The gateway also runs under Docker for other platforms (see the install guide). Requires LMS 9.0 or later.

## Known limitations

- Play counts from offline listening aren't sent back to LMS yet.
- Native Android and iOS apps are planned; the installable web app covers phones and tablets for now.
