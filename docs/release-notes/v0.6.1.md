Lyrion Anywhere **0.6.1** fixes scrubbing in the web player on iPhone and iPad (issue #12). Everything else is as in [0.6.0](https://github.com/JameZUK/lyrion-anywhere/releases/tag/v0.6.0), which added the built-in Cloudflare Tunnel. Android [1.15.5](https://github.com/JameZUK/lyrion-anywhere/releases/tag/android-v1.15.5) remains current. Update from *Settings › Plugins* in LMS; LMS restarts to load it. **Install or update:** add this repository in *Settings › Plugins › Additional repositories* (if you haven't already), then install or update **Lyrion Anywhere**:

```
https://github.com/JameZUK/lyrion-anywhere/releases/latest/download/repo.xml
```

## Web app

- **Scrubbing at Original on iPhone and iPad no longer skips the track (#12).** On those devices the web player plays through the browser's media element, whose buffer memory is fixed, and a scrub at Original (FLAC) filled it. The player then waited for room that nothing made, playback ran dry, and a minute later the gateway closed the stream on purpose so the player would fetch the rest. Through a Cloudflare Tunnel that close could arrive looking like a normal end of the file, and the player took it as the end of the track. Now a full buffer frees the audio already played and carries on at once (Diagnostics shows *media buffer trimmed; resuming*), and every apparent end of a stream is confirmed with the gateway before the player moves on. The fix was worked out from the reporter's diagnostics and gateway log and is covered by tests; it was not reproduced on the author's devices, so reports either way are welcome on the issue.

The full list is in the [changelog](https://github.com/JameZUK/lyrion-anywhere/blob/main/CHANGELOG.md).
