Lyrion Anywhere lets your devices use this server securely over the internet, through the gateway this plugin runs. Put the gateway behind your HTTPS reverse proxy; never expose this server's own ports.

Out of the box, this server's own web and control ports (9000 and 9090) need no password on your local network, so anyone on it can change these settings. Remote accounts can only be changed from this page, not by other web sites, but if other people use your network, turn on password protection in Settings › Advanced › Security.

An http:// address sends passwords and sign-ins unencrypted. Use https://, unless this is a private address reached only over your VPN (see Trusted networks below), such as http://10.8.0.1:9443: then pairing links and QR codes work too.

[% END %] [% WRAPPER setting title="Trusted proxies" desc="IP addresses of reverse proxies on other machines (comma-separated). Leave empty if the proxy runs on this machine." %] [% END %] [% WRAPPER setting title="Trusted networks" desc="Private networks, such as your VPN, whose devices may connect without HTTPS (comma-separated, in CIDR form, e.g. 10.8.0.0/24). Devices on these networks connect unencrypted: passwords and sign-ins cross them in clear, so list only networks you control, such as your VPN. For this to work, set the Listen address above to the VPN interface's address, such as 10.8.0.1:9443: not 127.0.0.1, which the VPN cannot reach, and not 0.0.0.0, which offers the unencrypted listener to every network.

Users

Admins can control every player. Listeners control their own devices plus the home players you grant them. To sign in the Android app without typing a password, use Add a device: it shows a one-time code and a QR code for the app. In a web browser, people sign in with their username and password.

Stay signed in

How long a device stays signed in without being used: 1 to 365 days, 90 by default. Every use renews it, so devices in regular use never need to sign in again. Changes apply from each device's next use.

Cloudflare Tunnel

A Cloudflare Tunnel makes the gateway reachable from the internet with no open port, no certificate and no reverse proxy: this server dials out to Cloudflare, and Cloudflare serves your address. You need a domain on Cloudflare (the free plan is fine). Your music then flows through Cloudflare’s network, under Cloudflare’s terms. Cloudflare Tunnel is Cloudflare’s service; this plugin only sets it up for you.

Remove stops the tunnel and deletes cloudflared and the stored tunnel token from this server. The tunnel itself stays in your Cloudflare account until you delete it there.

Try a temporary tunnel

Test only. The address is random, Cloudflare gives no guarantee for it, and this plugin stops it after one hour. For everyday use, register a tunnel below.

No Cloudflare account is needed. Anyone who has the address can reach this server’s sign-in page until the temporary tunnel stops.

I have a tunnel token

In Cloudflare’s dashboard, create a tunnel (Networks › Tunnels › Create a tunnel › Cloudflared) and copy the token from the install command it shows.

In Cloudflare, give the tunnel the public hostname you want and set its service to http://127.0.0.1:9444.

Then paste the token and that hostname here.

Create it for me

The gateway creates the tunnel in your Cloudflare account, points it at this gateway and adds the DNS record. Create an API token in Cloudflare (My Profile › API Tokens) with these three permissions:

  • Account › Cloudflare Tunnel › Edit
  • Zone › DNS › Edit
  • Zone › Zone › Read

The API token is used once, for setting up the tunnel, and is never stored.
